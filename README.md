# Dietary fatty acid balance shapes spatial learning and landmark use in honey bees

This repository contains the datasets and analysis code accompanying the manuscript:

*Dietary fatty acid balance shapes spatial learning and landmark use in honey bees*

by Rozenbaum et al.

The repository includes the processed datasets underlying the analyses presented in the manuscript, documentation describing each dataset, and Python code used for the Monte Carlo simulations. Statistical analyses reported in the manuscript were conducted primarily in JMP Pro and R.

## Repository contents

The repository is organized into three main folders:

- **`data/`** – Processed datasets used in the analyses presented in the manuscript.
- **`docs/`** – Data dictionaries describing the variables in each dataset.
- **`python/`** – Python code used for the Monte Carlo simulations reported in the manuscript.

The repository also contains this `README.md` file describing the repository structure and contents.

## Datasets

The `data` folder contains the following datasets:
- **MazeLearning_Visits.csv** – Trial-level measures derived from arm visit sequences in the radial maze experiment.
- **MazeLearning_TimeAndDistance.csv** – Trial-level measurements of maze completion time and distance traveled in the radial maze experiment.
- **MonteCarlo_summary.csv** – Summary statistics from the Monte Carlo simulations.
- **MonteCarlo_distributions.csv.zip** – Simulated distributions generated by the Monte Carlo analyses (compressed because of file size).
- **FattyAcids.csv** – Fatty acid composition of individual bees used for analyses of dietary fatty acid balance.
- **LandmarkLearning.csv** – Trial-level data from the landmark-learning experiment.

## Data dictionaries

The `docs` folder contains data dictionaries describing the variables in each processed dataset.

- **MazeLearning_Visits_data_dictionary.xlsx** – Variable descriptions for `MazeLearning_Visits.csv`.
- **MazeLearning_TimeAndDistance_data_dictionary.xlsx** – Variable descriptions for `MazeLearning_TimeAndDistance.csv`.
- **FattyAcids_data_dictionary.xlsx** – Variable descriptions for `FattyAcids.csv`.
- **LandmarkLearning_data_dictionary.xlsx** – Variable descriptions for `LandmarkLearning.csv`.

## Python code

The `python` folder contains the Python code used for the Monte Carlo simulations reported in the manuscript.

- **MonteCarlo_trial8_CIs.py** – Performs the Monte Carlo simulations comparing the observed performance of bees with three null models and generates the output files `MonteCarlo_summary.csv` and `MonteCarlo_distributions.csv`.
- **Transition_probabilities_trial8.csv** – Input file containing the empirical transition probabilities measured in trial 8 that are used by the empirical null model.
